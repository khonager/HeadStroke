# Interface reference

`concept.png` was generated with the built-in image-generation tool for the compact phone view: light #f4f4f1 surface, dark canvas at 2:1, green primary button, two action rows, sensitivity slider, and a saved-drawing list.

The implementation keeps this hierarchy. Deliberate functional additions are the expandable controls/calibration help, guided setup, connection/preview explanation, error feedback, and deletion confirmation. The canvas itself and saved artwork are live code-rendered images, not generated artwork.

Prompt: a complete mobile HeadStroke drawing UI; header and sketchbook link, blank black 2:1 canvas with green crosshair, pause/start, recenter, save/new, sensitivity, shading instruction, empty gallery and connection status; restrained system typography, no marketing imagery. Generated reference is 853×1844; its intended CSS viewport is approximately 390×844.
